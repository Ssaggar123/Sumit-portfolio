## 🛠️ Built With

- HTML5
- CSS3 (Animations, Grid, Flexbox)
- No frameworks or libraries — pure vanilla

---

## ✨ Features

- Fade-in page animation on load
- Slide-down header effect
- Hover animations on sections, list items, and project cards
- Responsive two-column layout for Education & Skills
- Project cards with lift-on-hover effect

## 🚀 Deployment

This site is deployed on **Vercel**.  
Any push to the `main` branch triggers an automatic redeployment.

To run locally, simply open `index.html` in your browser — no build step needed.
